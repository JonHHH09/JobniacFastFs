# Home

JobniacFast is a local-first desktop app and MCP server for managing candidate profiles and job
postings, matching them deterministically, and generating tailored resume and cover-letter PDFs. It
runs on Windows, Linux and macOS (Apple Silicon), is built from a Rust core and a React and TypeScript
user interface on Tauri 2, and stores its data in an embedded SQLite file on your machine.

This wiki is generated from the `docs/wiki/` folder of the
[repository](https://github.com/JonHHH09/JobniacFastFs). To change a page, open a pull request
against `development`; edits made in the wiki editor are overwritten by the next sync.
